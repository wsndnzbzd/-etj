# 签文数据说明

## 当前数据文件
`app/src/main/assets/fortunes/guanyin_sensoji.json` 收录 100 支浅草寺系汉诗百签的签诗与签级。

## 来源与限制
- 数据来源：LudoBench《观音百签 — 全部一百支签》及其公开 JSON 接口。该来源说明签诗汇合四份公开列表，吉凶等级参考浅草寺相关列表；并明确说明尚未与实体签条核验。
- 来源页：https://ludobench.com/zh/fortunes/omikuji/book
- JSON 接口：https://api.ludobench.com/api/fortunes/books/omikuji
- **重要：这套是浅草寺系汉诗百签，不等同于华人庙宇常见的南海观音灵签。** 香港华人庙宇委员会也说明观音签存在不同地域版本：https://www.ctc.org.hk/zh-hans/chim-search/
- 白话、典故、事业/姻缘/财运解读目前留空，不能当成已完成的解签内容。后续应选定目标版本，再逐签补写并标明出处。

## 字段
每支签包含 `id`, `tradition`, `number`, `grade`, `poem`（四句数组）, `vernacular`, `allusion`, `overall`, `career`, `relationship`, `wealth`, `source`, `verification`。


## 现代解读字段（新增）

100 支签均已补充白话意译、整体解读、事业、感情/姻缘、财运、健康提示、家宅提醒与行动建议。除签诗及签级外，这些内容均为本项目原创现代参考解释，不是古籍原注，也不声称是寺庙正式解签。典故无法核实时不虚构具体人物或故事。

主数据来源：LudoBench《观音百签》公开汇编： https://ludobench.com/zh/fortunes/omikuji/book 。来源页称签诗汇集四份公开列表并逐字校合，但尚未与实体签条核验。该体系属于浅草寺系汉诗百签，不应与中国各地南海观音灵签混称。


## 月老灵签数据（新增）

- 数据文件：`app/src/main/assets/fortunes/yuelao.json`。
- 公开来源：https://knowyourbazi.com/zh-hans/yuelaoqian/
- 整理范围：流通本一百签及签王，共101条。公开来源列出签文、签级、白话大意和原典线索；不同寺庙版本可能不同。
- 项目自写部分：白话重述与新缘、现有关系、复合、婚姻、时机、行动建议分类，属于现代参考解读，不是庙方正式解签。
- 校勘限制：尚未逐条对照实体签条，也未为每一条完成原典版本、页码核验；部分签文按公开流通本录入，后续应逐条校对。

## 掷圣杯模拟说明
圣杯功能不是传统签文数据库，而是本地交互模拟。程序分别随机生成两枚杯筊的朝上面，再按一平一凸（圣杯）、双平面朝上（笑杯）、双凸面朝上（阴杯）分类。民间对杯筊面相和称呼可能存在地域差异；此处规则是为了让交互逻辑明确。连续三次圣杯才完成本轮确认，任何笑杯或阴杯都会重置连续计数。该功能不连接真实神明或外部服务。
